# Principles catalog

One row per checkable principle, across the recipes, house rules, conformance rules, the decision-tree leaves and the `@kit/ui` components. This file is the source of truth: `php bin/standards principles:compile` writes `principles.json` from it, and maps each row to its decision-tree leaf (`tree_leaf`) and the standards rule that checks it (`enforced_by`, `mode`).

Version: 2026-11-05

Sources:

- cookbook: `c129678eda8acaf4f12ab2341523900efe6846f9`
- tey/standards: v0.11.65
- tey/kit: v0.7.47 (kit-exports.json said v0.7.38)
- house-rules: `f7bbd2e0a9c50c1146cdf21077393bebe816cb36`

One row per checkable principle. Regex "how to check" entries find candidates, not proof. Prefixes: CONF conformance rule, recipe prefixes (VM, LNK, CTL, ...), HR house rule, STD standards leaf, KIT kit component.
